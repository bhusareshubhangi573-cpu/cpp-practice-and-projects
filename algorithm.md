# Algorithm
1. Start.
2. Initialize head and tail pointers to NULL.
3. Display the menu of operations.
4. Accept the user's choice.
5. If the choice is 1, insert a new bus stop at the beginning.
6. If the choice is 2, insert a new bus stop at the end.
7. If the choice is 3, search for and delete the specified bus stop.
8. If the choice is 4, search for a bus stop and display its position.
9. If the choice is 5, display all bus stops in forward order.
10. If the choice is 6, display all bus stops in reverse order.
11. If the choice is 7, terminate the program.
12. If the choice is invalid, display an error message.
13. Repeat the menu until the user selects Exit.
14. Stop.
