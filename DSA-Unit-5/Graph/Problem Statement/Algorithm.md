## Algorithm
1. Start.
2. Accept the warehouse locations from the user.
3. Create an empty adjacency list for each location.
4. Accept the aisle connections between locations.
5. Store each connection in both locations' adjacency lists.
6. Display the adjacent locations of every warehouse location.
7. Ask the user to select a warehouse location.
8. Display all locations directly connected to the selected location.
9. If the location is invalid or has no connections, display an appropriate message.
10. Stop.
