## Algorithm
1. Start the program.
2. Enter the warehouse locations.
3. Initialize an adjacency list for all locations.
4. Enter the aisle connections between warehouse locations.
5. Store each connection in both adjacency lists to represent an undirected graph.
6. Display the adjacent locations for each warehouse location.
7. Select a warehouse location.
8. Check whether the selected location is valid.
9. If the location is invalid, display an invalid location message and stop.
10. If the location is valid, check whether it has any adjacent locations.
11. If adjacent locations exist, display all directly accessible locations.
12. Otherwise, display a message indicating that no connections are available.
13. Stop the program.
