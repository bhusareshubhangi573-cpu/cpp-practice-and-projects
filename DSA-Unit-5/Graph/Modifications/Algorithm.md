
## Algorithm
1. Start the program.
2. Enter the warehouse locations.
3. Initialize the adjacency list for all locations.
4. Enter the aisle connections and store each connection in both adjacency lists.
5. Display the adjacent locations of each warehouse.
6. Insert a new warehouse location and its associated aisle connections.
7. Display the updated graph.
8. Select an aisle connection and remove it from both adjacency lists.
9. Display the updated graph after edge deletion.
10. Select a warehouse location.
11. Check whether the selected location is valid.
12. If the location is invalid, display an invalid location message.
13. Otherwise, calculate and display its degree or display its direct neighbours.
14. Stop the program.
