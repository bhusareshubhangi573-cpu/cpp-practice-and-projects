## Algorithm
1. Start the program.
2. Initialize an empty AVL tree.
3. Insert the elements using BST insertion rules.
4. Update the height of each node.
5. Calculate the balance factor.
6. Detect the RR imbalance.
7. Display the balance factor before rotation.
8. Perform a left rotation.
9. Update the heights and display the balance factors after rotation.
10. Count the rotations performed.
11. Display the inorder traversal and final root.
12. Verify the AVL balance condition.
13. Repeat the test using another sequence that causes an RR imbalance.
14. Stop.
