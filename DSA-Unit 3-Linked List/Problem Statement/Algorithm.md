
## Algorithm

1. Start the program.
2. Create an empty singly linked list by setting `head = NULL`.
3. Display a menu with the following operations:
   - Insert a bus stop at the beginning.
   - Insert a bus stop at the end.
   - Delete a bus stop.
   - Search for a bus stop.
   - Display all bus stops.
   - Exit.
4. Accept the user's choice.
5. Perform the selected operation:
   - **Insertion at Beginning:** Create a new node and link it before the current head.
   - **Insertion at End:** Create a new node and attach it to the last node.
   - **Deletion:** Search for the given bus stop and remove its node from the list.
   - **Searching:** Traverse the list and check whether the given bus stop exists.
   - **Display:** Traverse the list and print all bus stop names.
6. Display the result of the selected operation.
7. Repeat the menu until the user selects Exit.
8. Stop the program.
