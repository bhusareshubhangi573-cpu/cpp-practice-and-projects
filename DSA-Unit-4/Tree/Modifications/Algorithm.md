# Algorithm

1. Start.
2. Create an empty AVL tree.
3. Insert elements using BST insertion rules.
4. Update the height of affected nodes.
5. Calculate the balance factor of each affected node.
6. Check whether any node is unbalanced.
7. If an RR imbalance occurs, identify the unbalanced node.
8. Display balance factors before rotation.
9. Perform a left rotation to balance the tree.
10. Update heights and display balance factors after rotation.
11. Increase the rotation count.
12. Repeat the insertion process until all elements are inserted.
13. Display the final balanced AVL tree and total rotation count.
14. Check whether another test sequence is available.
15. If yes, reset the tree and rotation count, then repeat the process.
16. If no, stop.
