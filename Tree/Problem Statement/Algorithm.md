## Algorithm

1. Start the program.
2. Create a node structure containing data, height, and left and right pointers.
3. Insert the elements 10, 20, and 30 into the AVL tree in sequence.
4. Update the height of each node after insertion.
5. Calculate the balance factor of each affected node.
6. Check for an RR imbalance at node 10.
7. Perform a left rotation at node 10 to restore balance.
8. Update the heights of the rotated nodes.
9. Display the final balanced AVL tree.
10. Stop the program.
