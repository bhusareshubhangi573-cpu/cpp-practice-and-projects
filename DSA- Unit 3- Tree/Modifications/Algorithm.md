## Algorithm

1. Start the program.
2. Create an empty AVL tree.
3. Insert the elements 10, 20, and 30 one by one.
4. Update the height of each node after insertion.
5. Calculate the balance factor of the affected nodes.
6. Identify the RR imbalance at node 10.
7. Display the balance factors before rotation.
8. Perform a left rotation to balance the tree.
9. Update the heights and display the balance factors after rotation.
10. Count the rotations performed during insertion.
11. Display the final balanced AVL tree and the total number of rotations.
12. Test the program with another sequence, such as 10, 20, 30, 40, and 50.
13. Display the results of the additional test.
14. Stop the program.
