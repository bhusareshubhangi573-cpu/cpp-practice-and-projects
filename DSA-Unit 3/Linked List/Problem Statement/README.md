## Problem Statement
Implement a singly linked list to maintain bus stop names. Perform insertion at the beginning and end, deletion of a bus stop, and searching for a bus stop in the list.

## Approch
- Create a node containing a bus stop name and a pointer to the next node.
- Insert a new bus stop at the beginning of the list.
- Insert a new bus stop at the end of the list.
- Delete a bus stop using its name.
- Search for a bus stop in the list.
- Display all bus stops in sequence.


## Time and Space Complexity

### Time Complexity

| Operation | Time Complexity |
|---|---|
| Insertion at Beginning | O(1) |
| Insertion at End | O(n) |
| Deletion of a Bus Stop | O(n) |
| Searching a Bus Stop | O(n) |
| Displaying Bus Stops | O(n) |

### Space Complexity

**Space Complexity:** O(n)

Here, n represents the total number of bus stops in the linked list. Each bus stop is stored in a separate node.

## Conclusion
The Bus Stop Management system using a Singly Linked List helps to manage bus stop names efficiently. It allows insertion of bus stops at the beginning and end, deletion of a bus stop, and searching for a particular stop. This project helps to understand the basic operations of a linked list and how nodes are connected using pointers. It also shows how linked lists can be used to manage data dynamically.
